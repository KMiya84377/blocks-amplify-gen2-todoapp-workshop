# blocks-amplify-gen2-todoapp-workshop

## 概要

このワークショップでは、AWS Amplify Gen2 と AWS Blocks を組み合わせて、ログイン機能・AIエージェント付きの Todo アプリケーションを構築します。

## 前提条件

- AWS アカウント（Admin 相当の権限）
- GitHub アカウント
