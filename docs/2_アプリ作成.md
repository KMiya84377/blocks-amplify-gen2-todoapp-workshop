# アプリ作成

## 前提条件

- Node.js 22以上
- npm 10以上

## セットアップ

**作業目安：15分**

### プロジェクトの作成

1. フロントエンドのプロジェクトを作成します。

```shell
npm create vite@latest todo-app -- --template react-ts
```

> [!NOTE]
>
> 実行すると、途中で Lint ツールの選択画面が表示されます。デフォルトの `Oxlint` を選んでください。

2. 作成したプロジェクトのディレクトリに移動し、Amplify Gen2 のバックエンドを追加します。

```shell
cd todo-app
npm create amplify@latest -- --template react-vite
```

`amplify/auth/resource.ts`・`amplify/data/resource.ts`が生成されますが、本ワークショップではこれらは使いません（Auth・DataはどちらもBlocks側で作ります）。触らずそのままにしておいて問題ありません。

3. Blocksを追加します。`amplify/backend.ts`が検出され、`amplify`テンプレートが自動選択されます。

```shell
npx @aws-blocks/create-blocks-app .
```

`aws-blocks/`ディレクトリが作られます。

> [!NOTE]
>
> `amplify`テンプレートのデフォルトで組み込まれるBuilding Blockは`KVStore`のみです。認証（`AuthCognito`）・Todoデータ（`DistributedTable`）は、これから自分で追加していきます。

### ローカルサーバーの起動

Blocksにはローカル完結の開発サーバーがあります。AWSアカウントへのデプロイなしで開発を進められます。

```shell
npm run blocks:dev
```

`http://localhost:3001`でBlocksのAPIサーバーが起動します。データは`.bb-data/`ディレクトリにファイルとして保存されます（削除すればリセットできます）。

> [!TIP]
>
> `npm run blocks:dev`はin-memoryモックで動くため、AWSクレデンシャルは不要です。実際にAWSへデプロイする（`npm run sandbox`）のは、[4_ホスティング.md](4_ホスティング.md)で行います。

続けて、Viteの開発サーバーも起動します。

```shell
# 新しいターミナルを起動
npm run dev
```

`http://localhost:5173/` を開くと、Viteの初期画面が表示されれば完了です。

## ログイン画面の実装

**作業目安：15分**

Blocksの`AuthCognito`で認証機能を作ります。Cognitoベースの認証ですが、ローカル開発中(`npm run blocks:dev`)は本物のCognitoを使わずモックで動きます。実際のCognito User Poolが作られるのは、AWSへデプロイした時だけです。

1. `aws-blocks/index.ts`の中身を、以下のように書き換えます（`Scope`の宣言から始めます。以降の章もこの同じファイルに追記していきます）。

```typescript title="aws-blocks/index.ts"
import { Scope, AuthCognito } from '@aws-blocks/blocks';

const scope = new Scope('app');

const auth = new AuthCognito(scope, 'auth', {
  passwordPolicy: { minLength: 8, requireDigits: true },
});

export const authApi = auth.createApi();
```

> [!NOTE]
>
> `authFlowType`に`USER_SRP_AUTH`・`CUSTOM_AUTH`は指定できません(コンストラクタの時点でエラーになります)。デフォルトのまま(未指定)か、`USER_PASSWORD_AUTH`等を使ってください。

2. フロントエンドに、Blocksの汎用UI関数`Authenticator`を組み込みます。`Authenticator`はReactコンポーネントではなく、`HTMLElement`を返す素のDOM関数です。Reactでは`ref`+`useEffect`でマウントします。

ログイン状態の変化は`onAuthChange(api, callback)`で監視できます。`callback`は`AuthUser | null`を受け取り、戻り値は購読解除関数なので、そのまま`useEffect`のクリーンアップに使えます。

```tsx title="src/App.tsx(抜粋)"
import { useEffect, useRef, useState } from 'react'
import { authApi } from 'aws-blocks'
import { Authenticator, onAuthChange } from '@aws-blocks/blocks/ui'

function App() {
  const authRef = useRef<HTMLDivElement>(null)
  const [user, setUser] = useState<{ userId: string; username: string } | null>(null)

  useEffect(() => {
    const el = Authenticator(authApi)
    authRef.current?.appendChild(el)
    return () => { authRef.current?.removeChild(el) }
  }, [])

  useEffect(() => onAuthChange(authApi, setUser), [])

  if (!user) {
    return <div ref={authRef} />
  }

  return (
    <section id="todo">
      <p>ようこそ、{user.username} さん</p>
      {/* Todo一覧はここに続く */}
    </section>
  )
}
```

`authApi`は`import { authApi } from 'aws-blocks'`で、バックエンドの`aws-blocks/index.ts`が`export`したものが、Proxy経由のAPIクライアントとしてフロントエンドから直接importできます(`npm run blocks:generate-client`で生成される仕組み)。

ブラウザを再読み込みすると、サインアップ・サインイン画面が表示されます。アカウントを作成し、ログイン済みの状態にしてください。

## Todo機能の実装

**作業目安：15分**

Todoデータは、Blocksの`DistributedTable`で自前のテーブルとして持ちます（Amplify Dataは使いません）。`owner`をパーティションキー、`id`をソートキーにすることで、GSIなしで「自分のTodoだけ」を絞り込めます。

1. `aws-blocks/index.ts`にTodoテーブルとAPIを追加します。`import`文に`DistributedTable`・`ApiNamespace`を追加し、`z`のimportも追加します。

```typescript title="aws-blocks/index.ts(追記)"
import { Scope, AuthCognito, DistributedTable, ApiNamespace } from '@aws-blocks/blocks';
import { z } from 'zod';

// scope・authの宣言はそのまま

const todoSchema = z.object({
  id: z.string(),
  text: z.string(),
  done: z.boolean(),
  owner: z.string(),
});

const todos = new DistributedTable(scope, 'todos', {
  schema: todoSchema,
  key: { partitionKey: 'owner', sortKey: 'id' },
});

export const api = new ApiNamespace(scope, 'api', (context) => ({
  async listTodos() {
    const user = await auth.requireAuth(context);
    return await Array.fromAsync(todos.query({ where: { owner: { equals: user.username } } }));
  },
  async createTodo(text: string) {
    const user = await auth.requireAuth(context);
    const id = `todo-${Date.now().toString(36)}`;
    const todo = { id, text, done: false, owner: user.username };
    await todos.put(todo);
    return todo;
  },
  async toggleTodo(id: string, done: boolean) {
    const user = await auth.requireAuth(context);
    const todo = await todos.get({ owner: user.username, id });
    if (!todo) throw new Error('not found');
    await todos.put({ ...todo, done });
  },
  async deleteTodo(id: string) {
    const user = await auth.requireAuth(context);
    await todos.delete({ owner: user.username, id });
  },
}));
```

`DistributedTable`に`.update()`はないため、`toggleTodo`は`get()`で現在の値を取ってから`put()`で書き戻すread-modify-writeにしています。

2. `npm run blocks:generate-client`でフロントエンド用クライアントを再生成します。

```shell
npm run blocks:generate-client
```

3. `src/App.tsx`を、ログイン画面(手順2)とTodo一覧を組み合わせた完全な形に書き換えます。Amplify Dataの`observeQuery`のようなリアルタイム購読は無いため、操作のたびに`listTodos()`を呼び直します。

```tsx
import { useEffect, useRef, useState } from 'react'
import { api, authApi } from 'aws-blocks'
import { Authenticator, onAuthChange } from '@aws-blocks/blocks/ui'

type Todo = { id: string; text: string; done: boolean; owner: string }
type User = { userId: string; username: string }

function TodoSection({ user }: { user: User }) {
  const [todos, setTodos] = useState<Todo[]>([])
  const [text, setText] = useState('')

  const refresh = async () => setTodos(await api.listTodos())

  useEffect(() => { refresh() }, [])

  async function addTodo() {
    if (text.trim() === '') return
    await api.createTodo(text)
    setText('')
    await refresh()
  }

  async function toggleTodo(todo: Todo) {
    await api.toggleTodo(todo.id, !todo.done)
    await refresh()
  }

  async function deleteTodo(id: string) {
    await api.deleteTodo(id)
    await refresh()
  }

  return (
    <section id="todo">
      <p>ようこそ、{user.username} さん</p>
      <h1>TODO</h1>
      <div className="todo-form">
        <input value={text} onChange={(e) => setText(e.target.value)} placeholder="やることを入力" />
        <button onClick={addTodo}>追加</button>
      </div>
      <ul className="todo-list">
        {todos.map((todo) => (
          <li key={todo.id} className={todo.done ? 'done' : ''}>
            <input type="checkbox" checked={todo.done} onChange={() => toggleTodo(todo)} />
            <span>{todo.text}</span>
            <button className="delete" onClick={() => deleteTodo(todo.id)}>×</button>
          </li>
        ))}
      </ul>
    </section>
  )
}

function App() {
  const authRef = useRef<HTMLDivElement>(null)
  const [user, setUser] = useState<User | null>(null)

  useEffect(() => {
    const el = Authenticator(authApi)
    authRef.current?.appendChild(el)
    return () => { authRef.current?.removeChild(el) }
  }, [])

  useEffect(() => onAuthChange(authApi, setUser), [])

  if (!user) {
    return <div ref={authRef} />
  }

  return <TodoSection user={user} />
}

export default App
```
