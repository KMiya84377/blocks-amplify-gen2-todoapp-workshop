# 初期設定

## 事前準備

### アカウント作成

本ワークショップは以下のアカウントが事前に作成されていることを前提としています。

- AWS アカウント（Admin 相当）
  - マネージメントコンソールにアクセスできるユーザーを用意してください。
  - MFA 必須のユーザーは利用できません。
- GitHub アカウント
  - GitHub Codespaces を利用可能なアカウントを用意してください。
  - 作成手順は[公式情報](https://docs.github.com/ja/get-started/start-your-journey/creating-an-account-on-github)を参照してください。

アカウントがない場合は、作成してから続きを進めてください。

## テンプレートのコピー

本ワークショップは GitHub Codespaces 上で実行されることを想定しています。
別の環境を使用される場合は、適宜読み替えて進めてください。

**作業目安：10分**

### リポジトリのテンプレート作成

本ワークショップのテンプレートリポジトリから、自分のアカウントに新しいリポジトリを作成します。

1. [ワークショップテンプレートリポジトリ](https://github.com/KMiya84377/blocks-amplify-gen2-todoapp-workshop)にアクセス
2. 右上の「Use this template」ボタンをクリック
3. 「Create a new repository」を選択
4. リポジトリ名を入力（`blocks-amplify-gen2-todoapp-workshop` で作成してください）
5. 「Private」 を選択
6. 「Create repository」ボタンをクリック

> **意図せずPublicで作成した場合**
> 一度削除して作成し直すことをお勧めします。

### Codespaces で開く

作成したリポジトリを GitHub Codespaces で開きます。

[GitHub Codespaces とは？](https://docs.github.com/ja/codespaces/about-codespaces/what-are-codespaces)

1. 作成したリポジトリのページで「Code」ボタンをクリック
2. 「Codespaces」タブを選択
3. 「Create codespace on main」ボタンをクリック

Codespaces が起動し、開発環境が自動的にセットアップされます。
5 分程度かかりますので、お待ちください。

この後は、基本的に Codespaces のエディタ内で作業をしていきます。

> **ローカル環境で作業する場合**
> 以下のコマンドでクローンしてください。
>
> ```shell
> git clone https://github.com/[your-username]/[repository-name].git
> cd [repository-name]
> ```

## インストール(設定済み)

**作業目安：5分**

AWS CLI と Node.js は Dev Containers によりインストール済みです。

[Dev Containers とは？](https://docs.github.com/ja/codespaces/setting-up-your-project-for-codespaces/adding-a-dev-container-configuration/introduction-to-dev-containers)

> **devcontainer.jsonについて**
> `.devcontainer` ディレクトリの `devcontainer.json` ファイルに本ワークショップで利用する環境の設定が記載されています。

1. 設定が完了しているか、以下のコマンドで確認してください。

```shell
aws --version
# aws-cli/2.x.x ...

node -v
# v24.x.x
```

エラーなく実行できれば完了です。
AWSへのログインは、実際にAWSを使う4章（ホスティング）で行います。

ここまで確認できたら、次のステップ（[docs/2_TODOアプリ作成 by AWS Blocks.md](2_TODOアプリ作成%20by%20AWS%20Blocks.md)）に進んでください。
